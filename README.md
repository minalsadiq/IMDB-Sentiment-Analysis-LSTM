# IMDb Sentiment Analysis using LSTM

## Project Overview
This project performs sentiment analysis on the IMDb movie review dataset using an LSTM (Long Short-Term Memory) deep learning model.

The project includes complete NLP preprocessing, data analysis, model training, evaluation, and visualization.


## Dataset
Dataset used: IMDb Movie Reviews Dataset

The dataset contains movie reviews labeled as:
- Positive
- Negative

## Steps Performed

### Data Analysis
- Checked dataset structure
- Checked missing values
- Filled missing values
- Analyzed label distribution

### Data Preprocessing
- Text cleaning
- Tokenization
- Label encoding
- Feature extraction
- Train-test split

### Model Building
- Implemented LSTM model
- Applied epochs for training
- Generated accuracy graphs

### Evaluation
- Classification report
- Confusion matrix
- Accuracy comparison

## Technologies Used
- Python
- Google Colab
- TensorFlow / Keras
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Results
The LSTM model successfully classified IMDb reviews into positive and negative sentiments with good accuracy.
