# IMDB Sentiment Analysis using LSTM

A Deep Learning project to classify IMDb movie reviews as **Positive** or **Negative** using an LSTM (Long Short-Term Memory) network.

## 🚀 Project Overview
This project processes the IMDb dataset to build a sentiment analysis model. It covers the entire lifecycle from data cleaning and preprocessing to building a sequence-based neural network.
## Dataset
Dataset used: IMDb Movie Reviews Dataset

The dataset contains movie reviews labeled as:
- Positive
- Negative

## 🛠 Tech Stack
* **Language:** Python
* **Deep Learning:** TensorFlow / Keras
* **Data Processing:** Pandas, NumPy
* **Visualization:** Matplotlib
* **Evaluation:** Scikit-learn

## 📊 Methodology
| Stage | Description |
| :--- | :--- |
| **Data Analysis** | Exploratory Data Analysis (EDA) and cleaning. |
| **Preprocessing** | Tokenization, padding, and label encoding. |
| **Model** | LSTM architecture for sequence data. |
| **Evaluation** | Confusion matrix and accuracy metrics. |
